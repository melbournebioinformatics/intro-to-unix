## Delivery

- Anticipated duration is **3 hours** when delivered to a group.
- The workshop runs on individual [Nectar](https://cloud.nectar.org.au/) instances so that every
  learner has an identical environment. Provide each participant with a username, IP address and
  password at the start.
- A short slide presentation introduces Unix concepts before the hands-on work — see
  `learners/files/unix_intro_slides.pdf` (and `.pptx`).

## Per-episode notes

- **02 Getting started**: connection details live on the Setup page, which links out to the
  *Intro to the Nectar Cloud* lesson. Confirm everyone can log in before moving on.
- **06 Removing files**: emphasise the `rm` caution box — deletions are permanent. Discourage
  combining `rm` with wildcards.
- **09 Transferring files**: this section is **for in-person participants only** (it needs the
  provided Nectar instance). Remind learners to copy any work off the instance before it is shut
  down after the workshop.

## Independent / online learners

- macOS/Linux learners run locally after downloading the data zip from the Setup page (or Zenodo).
- Windows learners use the binder linked from Setup; note that `man` pages may not work in binder.
