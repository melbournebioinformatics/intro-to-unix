## What is Unix?

Knowledge of the Unix operating system is fundamental to the use of many popular bioinformatics
command-line tools. Whether you choose to run your analyses locally or on a high-performance
computing (HPC) system, knowing your way around a command-line interface is highly valuable.

This workshop introduces Unix concepts through a series of hands-on exercises. It is designed for
participants with little or no command-line knowledge, and provides the background skills required
for several other Melbourne Bioinformatics workshops that work on the command line.

By the end of this lesson you will be able to:

- Access a Unix machine, either locally or remotely
- Navigate the file system
- Organise your files into directories
- Change file permissions to improve security and safety
- Move and copy files between directories
- Safely remove files
- Perform searches within files
- Combine commands using pipes
- Transfer files between a local and a remote machine

## How to use this lesson

Grey boxes are **code blocks**. Type each command into your terminal and press <kbd>Enter</kbd>.
Use the copy button in the top right-hand corner of the box to copy a command to your clipboard.

